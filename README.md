# say-it-simply

It follows a simple philosophy: just keep it simple.

A skill that stops your coding agent from burying the answer. It shapes what the agent says to you,
not how it thinks.

## Install

Copy `skills/say-it-simply/` into your harness's skills folder, or paste its lines into `AGENTS.md`.
